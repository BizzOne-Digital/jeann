# Legal PDF uploads

Place counsel-approved PDF files in this folder using **exact filenames**:

| File | Website page |
|------|----------------|
| `finekarts-terms-of-use.pdf` | /terms |
| `finekarts-privacy-policy.pdf` | /privacy |
| `finekarts-buyer-terms.pdf` | /buyer-terms |
| `finekarts-general-conditions-of-sale.pdf` | /resources |
| `finekarts-incoterms-reference.pdf` | /trade |
| `finekarts-anti-bribery-compliance.pdf` | /resources |

After upload, redeploy (or commit + push if using Git deploy). Download links appear automatically on legal pages.

Until PDFs are present, the site shows web summaries with a “PDF pending legal review” notice.
